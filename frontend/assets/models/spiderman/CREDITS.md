# Spider-Man 3D model

- "Marvel Spider Man (2002 Movie Version)" by LykoModels — https://www.renderhub.com/lykomodels/marvel-spider-man-movie-2002
- Downloaded free from RenderHub under its **Extended Use License (IP Restricted)**: editorial use only, because the
  character is Marvel / Sony IP. Fine for a personal prototype; not for a commercial product.
- Files: `spiderman.fbx` (Mixamo skeleton, 10k polys) + `spiderman.jpg` (the original 2048² TGA texture, converted to JPG).

- `spiderman.glb`: compressed (meshopt) conversion of the original `spiderman.fbx`, which is in git history (commit 002abb8).
